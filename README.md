# Python Employee Card Workshop

This project is a beginner-friendly Python exercise focused on working with strings and basic data types.

## What I Learned

* Creating and storing strings
* String concatenation using `+`
* Using the `+=` operator
* Converting integers to strings with `str()`
* Creating formatted strings with f-strings
* String slicing
* Positive and negative indexing
* Working with strings and integers

## Project Features

The program creates an employee card containing:

* Employee name
* Address
* Age
* Work experience
* Position
* Salary
* Employee code
* Department
* Year code
* Initials
* Employee ID

## Technologies Used

* Python 3
